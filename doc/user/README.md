# User guides

Boltra creates and runs ordinary FastAPI projects using a Python CLI.

1. [Install Boltra](installation.md) — source checkout, isolated tool install, and troubleshooting.
2. [Create and extend an app](quickstart.md) — a complete working example.
3. [CLI reference](cli.md) — commands, flags, configuration, and exit statuses.
4. [Settings reference](settings.md) — environment variables, defaults, and caching.

Currently available: help, version, project generation, settings scaffolding, and
reloadable development serving. App management, ORM, admin, authentication, and
other batteries are [planned](../plan/phase.md).
